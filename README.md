# Zalith 1 → 2 Control Converter

Convert **Zalith Launcher 1** / Pojav / FCL control JSON (`mControlDataList`) into **Zalith Launcher 2** layouts (`editorVersion` + layers).

## Live site

After enabling GitHub Pages:

**https://hackfireoffical.github.io/zalith-1-to-2-control/**

### Enable Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch** → branch **main** → folder **/ (root)**  
   *or* use the included GitHub Actions workflow
3. Save and wait ~1 minute

## Usage

1. Open the site
2. Drop or paste a ZL1 control `.json`
3. **Convert** → **Download ZL2 JSON**
4. Zalith Launcher 2 → **Settings → Control list** → import

## Features

- Buttons, keycodes, special buttons (Keyboard, PRI/SEC, middle mouse, scroll)
- Visibility → ZL2 layers (`always` / `in_game` / `in_menu`)
- Joysticks (basic)
- Styles from ZL1 colors/opacity/radius
- Runs 100% in the browser
