How to use the converted file in Zalith Launcher 2
  1. Download the converted .json.
  2. On your phone: Zalith Launcher 2 → Settings → Control list.
  3. Import / share the JSON into the control layouts folder.
  4. Open the layout in the editor and tweak positions if needed — conversion approximates ZL1 dynamic expressions on a reference resolution.

Special buttons (Keyboard, GUI toggle, mouse left/right/middle, scroll) are mapped where possible. Drawer groups are flattened. Middle mouse uses GLFW_MOUSE_BUTTON_MIDDLE.
